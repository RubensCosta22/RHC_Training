# RHC Training v1.0.0

Release date: 2026-08-11

RHC Training v1.0 marks the production cutover to Database V2 and the completion of the first stable production milestone.

## Highlights

- simplified identity and authorization model without families/family_members;
- separate global admin account and explicit profile access;
- preserved Henrique training history during database migration;
- A–F workout support, including running and structured program progression;
- atomic cloud workout drafts with refresh/reopen recovery;
- secure archive/restore for workouts, measurements and photos;
- progress and administration statistics migrated to V2;
- mobile/PWA production deployment on Render;
- structured/redacted observability and security CI;
- history search, filters and server-side pagination;
- archived-item search and category filtering;
- canonical reproducible Database V2 baseline and integrity/RLS tests.
